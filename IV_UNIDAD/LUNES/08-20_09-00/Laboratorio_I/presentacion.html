Introducción a C++: Tipos Estrictos y Compilación

Un recorrido conceptual y práctico por la estructura formal, la gestión de memoria y el proceso de compilación nativa en C++.

Curso: Laboratorio I Grado: 4º Bachillerato (4BACO)
Visión General

¿Qué vamos a aprender en esta guía?

Compilación vs. Interpretación

Entender por qué C++ traduce a código máquina (.exe) directo y cómo optimiza la velocidad.

Tipado Estricto de Datos

Por qué C++ exige declarar los tipos de datos (int, double, string) antes de ejecutar.

Sintaxis Formal y Librerías

Estructura esencial: #include <iostream>, función main() y using namespace std;.

Entrada y Salida Interactivas

Flujo de datos en consola con cin >> y cout << y manejo de errores sintácticos.

Objetivo CNB: Crear aplicaciones estructuradas aplicando sintaxis formal y compilación directa para optimizar la memoria.
Introducción Tecnológica

¿Qué es C++ y por qué es tan relevante?

Alto Rendimiento

Acceso de bajo nivel a la memoria física del equipo, lo que genera ejecuciones ultrarrápidas sin intermediarios.

Lenguaje Compilado

El código fuente escrito por el programador se traduce completamente a código binario nativo (.exe) antes de ejecutarse.

Estándar Industrial

Utilizado para crear motores de videojuegos (Unreal Engine), sistemas operativos, navegadores web y software crítico.

Evolución: C++ fue diseñado por Bjarne Stroustrup como una extensión del lenguaje C, agregando tipos de datos estrictos y orientación a objetos.
Fundamento Técnico

Compilación vs. Interpretación

Característica Python (Interpretado) C++ (Compilado)
Ejecución Línea por línea mediante un intérprete. Traduce TODO el código fuente antes de ejecutar.
Producto Final Requiere el instalador de Python. Genera un archivo ejecutable directo (.exe).
Velocidad Más lento (revisa errores en tiempo de ejecución). Ultra rápido (código máquina directo).
Detección de Errores El programa se detiene cuando llega al error. El compilador rechaza generar el .exe si hay errores.
Analogía didáctica: Un lenguaje interpretado es como tener un traductor simultáneo leyendo párrafo por párrafo; un lenguaje compilado traduce el libro completo de antemano.
Gestión de Memoria RAM

¿Qué es el Tipado Estricto?

Python (Tipado Dinámico) Implícito 
x = 10

El sistema adivina el tipo de dato durante la ejecución. Consume más recursos porque debe monitorear el tipo en tiempo real.

C++ (Tipado Estricto) Explícito 
int x = 10;

Debes declarar obligatoriamente el tipo (int). El compilador reserva exactamente la cantidad de bytes requerida en la memoria RAM antes de iniciar.

Ventaja Clave: Al saber con anticipación que int requiere 4 bytes, C++ organiza la memoria de forma óptima sin desperdiciar almacenamiento.
Anatomía del Código

Estructura Básica de un Programa en C++

#include <iostream> // Directiva de preprocesador
#include <string> // Soporte para cadenas de texto
using namespace std; // Espacio de nombres estándar
int main() { // Función principal (Punto de entrada)
// Bloque de código principal
cout << "¡Hola Cuarto Bachillerato!" << endl;
return 0; // Retorno exitoso al sistema operativo
}
1. Directivas (#include)

Cargan las herramientas previas necesarias antes de compilar.

2. Espacio de nombres

Evita tener que escribir std:: antes de cada comando.

3. Función main()

El punto exacto donde la computadora empieza a ejecutar.

Directiva de Preprocesador

La librería <iostream>

Input / Output Stream (Flujo de Entrada y Salida)

Es una directiva de preprocesador que le indica al compilador que añada la biblioteca estándar para el manejo de consola antes de iniciar la compilación.

Habilita cin Captura la entrada de datos desde el teclado.
Habilita cout Muestra datos y mensajes impresos en la pantalla.
Atención: Sin #include <iostream>, el compilador marcará un error fatal indicando que los objetos cin y cout no han sido declarados.
Espacios de Nombres

using namespace std;

Sin `using namespace std;`

Debes escribir el prefijo std:: en cada instrucción de entrada, salida o salto de línea:

std::cout << "Hola" << std::endl;
std::cin >> edad;

Con `using namespace std;`

Importas el espacio de nombres completo y escribes comandos directos y limpios:

cout << "Hola" << endl;
cin >> edad;
¿Qué es un namespace? Es una "carpeta conceptual" que agrupa herramientas del sistema para evitar colisiones de nombres si creas tus propias funciones con nombres similares.
Punto de Entrada

La Función Principal int main()

Puerta de Entrada Obligatoria

C++ no ejecuta código fuera de una función. El compilador busca automáticamente la función llamada main() para iniciar el programa.

Significado de return 0;

Como la función devuelve un entero (int), retornar un valor 0 le notifica formalmente al Sistema Operativo que el programa finalizó con éxito y sin errores.

Cualquier número distinto de 0 (ej. return 1;) le avisaría al sistema que ocurrió un fallo o anomalía.
Clasificación Estricta

Tipos de Datos Primarios en C++

int Números Enteros

Sin decimales. Ej. edad, cantidad de productos.

Ej: 16, 250, -5
double / float Números Decimales

Con punto decimal. double tiene el doble de precisión.

Ej: 88.75, 10.5
string Cadena de Texto

Secuencia de caracteres entre comillas dobles.

Ej: "Carlos Mendoza"
char Carácter Único

Un solo símbolo entre comillas simples.

Ej: 'A', 'M', 'F'
bool Booleano Lógico

Verdadero o Falso. En consola imprime 1 o 0.

Ej: true (1), false (0)

Cada tipo determina cuántos bytes exactos reserva la memoria RAM.

Sintaxis Formal

Declaración e Inicialización de Variables

string nombreEstudiante = "Carlos Mendoza";
int edad = 16;
double promedioGeneral = 88.75;
char seccion = 'A';
bool inscrito = true;

Desglose de la Fórmula:

[Tipo de Dato] + [Nombre Identificador] = [Valor Inicial] + ;
Regla de comillas: Cadenas de texto (string) usan comillas dobles " ", mientras que caracteres únicos (char) usan comillas simples ' '.
Impresión en Pantalla

Salida de Datos con cout

cout << "Nombre: " << nombreEstudiante << endl;
cout

Objeto de salida estándar (Console Output).

<< (Inserción)

Operador de inserción. "Empuja" los datos hacia la pantalla.

endl

End Line. Inserta un salto de línea y limpia el búfer.

Concatenación: Puedes encadenar múltiples textos y variables usando consecutivamente el operador <<.
Captura de Teclado

Entrada de Datos Interactivas con cin

cout << "Ingrese la cantidad: ";
cin >> cantidad;
1. Usuario Escribe en teclado
2. cin >> Extrae el dato
3. Variable Guarda en RAM
4. Proceso Realiza cálculos
¡No confundir los operadores!
cout << apunta las flechas hacia AFUERA (pantalla).
cin >> apunta las flechas hacia ADENTRO (variable).

Depuración Técnica

Errores Sintácticos y el Delimitador ;

Código con Error Sintáctico: 
int edad = 17 <-- ¡Falta ;!
cout << "Su edad es: " << edad;
Mensaje del Compilador (g++): error: expected ';' before 'cout'
¿Por qué es indispensable el punto y coma (;)?
A diferencia de Python (que usa saltos de línea e sangría), C++ ignora los espacios en blanco. El punto y coma le indica al compilador dónde termina exactamente una instrucción en la memoria.
Incompatibilidad de Tipos

Truncamiento Implícito en C++

int valor = 10.85; // Asignación incorrecta
¿Qué NO hace C++?

NO redondea el número a 11. C++ no aplica reglas de redondeo matemático automático.

¿Qué ocurre técnicamente?

Trunca (desecha) la parte decimal .85 y almacena únicamente el entero 10 en la memoria RAM.

Conclusión: Para preservar valores con decimales (precios, promedios) se debe utilizar obligatoriamente double o float.
